# Monster Truck Game

A React + Canvas mobile-friendly monster truck game.

## Features
- 2000 m course with 4 checkpoints, 3 lives and 52 coins (35 needed to finish)
- Three truck designs and three maps (Snow, Sea Side, Jungle)
- Wheelie, flip, nitro, brake skid, steep hills that need nitro
- Fuel stations every 300 m, engine heat system, water, mud and rope bridges
- Pause menu with volume and truck selection

## Controls
| Action  | Touch         | Keyboard        |
|---------|---------------|-----------------|
| Drive   | ◀ ▶           | ← → / A D       |
| Jump    | JUMP          | Space / W / ↑   |
| Wheelie | 🌀            | G               |
| Flip    | 🔄            | F               |
| Nitro   | 🚀            | N               |
| Pause   | ⏸ (top right) | P               |

## Run locally
```bash
npm install
npm run dev
```
Open the URL shown in the terminal.

## Build
```bash
npm run build
```
